# 🍔 Foodie Delight – Food Ordering Website

A simple and responsive food ordering website built using **HTML, CSS, and JavaScript**. Users can explore food categories, view featured items, and add products to the cart. This project is suitable for beginners and portfolio use.

---

## 🚀 Features
- Modern and clean user interface  
- Food categories (Pizza, Burgers, Sandwiches)  
- Featured food items with descriptions and prices  
- Add-to-cart functionality  
- Responsive design  

---

## 🛠️ Technologies Used
- **HTML** – Website structure  
- **CSS** – Styling and layout  
- **JavaScript** – Interactivity and cart logic
